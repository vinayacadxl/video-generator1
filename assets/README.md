# DoubtSolve.ai 2D / 3D Asset Library

Reusable educational assets for Remotion (2D) and Three.js (3D).

```
assets/
  physics/        # ball, train, car, rocket, projectile, spring, pendulum, wave
  mathematics/    # axes, graphs, geometry helpers
  chemistry/      # atom, electron, molecule, beaker
  biology/        # heart, lungs, cell, blood, dna
  general/        # arrows, icons, backgrounds, characters
```

Do not duplicate assets per lesson. Scene Director references these by id.
